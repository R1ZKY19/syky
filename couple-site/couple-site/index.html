✎ Cara Mengedit Website Ini

Semua konten website ini (nama, tanggal, foto, cerita, love letter, musik, pesan rahasia, dan password) diatur dari satu file:
config.js

1. Ganti teks
Buka config.js dengan text editor apa pun (Notepad, VS Code, dll), ubah nilainya, simpan, lalu refresh halaman ini.

2. Ganti foto
Taruh file foto kamu di folder assets/photos/, lalu ubah nama file di config.js pada bagian gallery, timeline, dan memories agar sesuai nama filenya.

3. Ganti musik
Taruh file musik (.mp3) di folder assets/music/, lalu ubah nama file di config.js pada bagian music.

4. Ganti password gerbang
Buka website ini, tekan F12 → tab Console, ketik: await sha256("password_baru"), lalu salin hasilnya ke gate.passwordHash di config.js.

Tombol ini (✎) hanya panduan — tidak menyimpan perubahan apa pun ke server, karena website ini murni file statis. Semua perubahan dilakukan langsung di config.js.
